# 중개광장

> 서로 다른 생각이 만나도, 이해가 시작되는 광장 — 세대도, 정치도, 함께

보수·진보, 청년·중장년·시니어가 각자의 마당에서 말하고, **자유광장**과 **정치싸움판**에서 만나 서로를 이해하는 정치 커뮤니티입니다.
**정책 참여**(국회 국민동의청원)와 **정책·법 소식**(입법예고·정부 정책 원문 + 의견 없는 AI 요약)으로 직접민주주의 참여도 돕습니다.

## 구역

| 메뉴 | 내용 |
|---|---|
| 홈 | 오늘의 핫 토픽 3개(자유광장), 실시간 인기 토론, 싸움판 카운트다운, 세대별 핫이슈, 주간 대결 주제 |
| 보수마당 · 진보마당 | 한 목록 + 세대 줄(청년/중장년/시니어). **내 세대 줄에만 글쓰기**, 읽기는 모두 자유 |
| 자유광장 | 누구나 글쓰기, 태그(자동 추천), 세대 마당 글 크로스 포스팅(“○○ 세대 관점”, 원문 연결) |
| 정치싸움판 | 한국 시간 **09–12시, 18–21시**에만 열림. 닫히면 잠금 화면 + 카운트다운 |
| 정책 참여 | 국회 국민동의청원 — 제목·내용·동의 수(1분마다 갱신)·청원 페이지 바로가기 |
| 정책·법 소식 | 국회 입법예고·정부 정책 — **원문과 AI 요약을 나란히**, 국회 의견 등록 바로가기 |
| 내 프로필 | 성향 배지·국적·연령대·중개인 점수·뱃지, 프로필 고치기, 내가 쓴 글 |

### 토론 규칙
- 투표는 **동의 / 반대 / 이해** — 글 하나당 한 번(다시 누르면 취소).
- 글쓴이의 **정치 성향 배지는 투표한 뒤에 공개**됩니다(편견 없이 읽기). 프로필에서 “바로 보기”로 바꿀 수 있어요.
- “이해”·“상대 의견 인정”을 **누르거나 받으면 중개인 점수 +1** → 1·10·50·200점 뱃지.
- 국적은 **접속 IP로 자동** 결정되며 직접 바꿀 수 없습니다. 해외 접속은 나라 구분 없이 똑같이 “해외 접속”으로 표시됩니다.

## 폴더 구조

```
public/                 ← 화면 (Vercel 이 그대로 서빙)
  index.html            ← 화면 뼈대 (Alpine.js 템플릿)
  assets/js/main.js     ← 시작 파일: 기능 모듈을 하나로 합침
  assets/js/config.js   ← 문구·메뉴·일정·용어 풀이 등 고정 설정
  assets/js/seed.js     ← 데모 데이터 (회원 5명·글 10개) + 연동 실패 시 예시
  assets/js/utils.js    ← 시간(KST)·저장소·형식 도우미
  assets/js/features/   ← ui · auth · board · battle · petitions · news
api/                    ← Vercel 서버 함수
  geo.js                ← 접속 국가 (Vercel IP 헤더)
  petitions.js          ← 국민동의청원 (열린국회정보)
  policy-news.js        ← 입법예고 + 정책브리핑 + Claude 요약
  _lib/                 ← 공용 코드 (주소로 노출되지 않음)
src/styles.css          ← Tailwind 입력 + 색 토큰(라이트/다크)
tests/                  ← node --test 단위 테스트
```

## 로컬에서 실행

```bash
npm install
npm run dev     # http://localhost:3000 (CSS 자동 빌드)
npm test        # 단위 테스트
```

로컬 정적 서버에는 `/api` 가 없어서 청원·소식은 **“예시 화면”** 표시와 함께 예시 데이터가 나옵니다.
서버 함수까지 함께 돌리려면 `npx vercel dev` 를 쓰세요.

## Vercel 배포

1. vercel.com → **Add New Project** → 이 저장소 선택 (설정은 `vercel.json` 이 자동 적용 — 빌드 `npm run build`, 출력 `public`)
2. **Settings → Environment Variables** 에 키 입력 (`.env.example` 참고)
   - `ASSEMBLY_API_KEY` — [열린국회정보](https://open.assembly.go.kr) 가입 후 무료 발급 **(청원·입법예고에 필수)**
   - `ANTHROPIC_API_KEY` — [Claude Console](https://platform.claude.com) 에서 발급 (없으면 원문만 표시)
3. 다시 배포(Redeploy)

### 배포 후 꼭 확인할 것
- `https://<도메인>/api/petitions?debug=1` — `source: "live"` 인지, `sampleKeys` 에 필드 이름이 어떻게 오는지 확인하세요.
  필드 이름이 다르면 `api/petitions.js` 의 `FIELDS` 후보에 추가하면 됩니다.
- 기본 목록(`PTTRCP`)은 **국회에 접수된(5만 명 달성 등) 청원**입니다. 지금 **동의를 받는 중인** 청원을 보여 주려면
  열린국회정보에서 “진행중 국민동의청원 현황” 서비스 코드를 찾아 `PETITION_LIST_CODE` 에 넣으세요 (코드 수정 불필요).
- 서버 함수는 **서울 리전(icn1)** 에서 돕니다 — 정부 사이트가 해외 IP를 막는 경우를 피하기 위함입니다.

### AI 요약 비용 (대략)
- 응답을 CDN 에 **1시간** 캐시하므로 AI 호출은 지역별로 한 시간에 한 번 정도입니다.
- 1회 요약(자료 8건) ≈ 입력 7천 + 출력 3~5천 토큰 → 기본 모델 `claude-opus-5-5` 기준 약 **$0.1/회, 월 $70 안팎**,
  `CLAUDE_MODEL=claude-haiku-5-5` 로 바꾸면 약 **월 $2 이하**입니다. (추정치 — 실제 요금은 platform.claude.com 사용량에서 확인)

### 보안 헤더(CSP) 참고
`vercel.json` 의 `Content-Security-Policy` 는 지금 쓰는 출처만 허용합니다.
Google AdSense·쿠팡 파트너스 스크립트를 붙일 때는 해당 도메인을 `script-src`·`frame-src`·`img-src` 에 추가하세요.

## 실서비스 전에 해야 할 일
- **로그인·회원 정보·글은 지금 브라우저(localStorage)에만 저장되는 데모**입니다. 실제 회원 DB, 카카오·네이버·구글 OAuth,
  서버 측 연령대·국적 확인(사용자가 바꿀 수 없게)이 필요합니다.
- 정치 성향은 개인정보보호법상 **민감정보**입니다 — 별도 동의, 최소 수집, 공개 범위 선택을 법률 검토와 함께 설계하세요.
- 신고·숨김 등 운영 도구, 이용약관·개인정보처리방침 정식 문안, 하단 “개발자 모드” 제거.

> 이제 이걸 WordPress 테마로 변환하고 싶다면? `public/` 화면을 `header.php`·`front-page.php` 로 나누고, 글은 `WP_Query`,
> 성향·연령대·국적은 `user_meta`, `/api/*` 는 WordPress REST API 엔드포인트로 옮기면 됩니다.
